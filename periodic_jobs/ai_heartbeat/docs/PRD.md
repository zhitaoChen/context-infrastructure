# 工作流记忆系统

## 目标

跨项目复用已验证的工程方法，不存储个人画像、业务机密或完整会话。
长任务恢复由目标项目检查点承担，不由长期记忆替代。

## 实现

`tools/brain/memory.py` 提供 capture、daily、weekly、status、render。
SQLite 是事实来源，Markdown 仅为生成视图，所有运行数据留在 Git 忽略的 `.local`。
Windows 计划任务在已登录用户下启动 CLI，关闭聊天窗口不影响；
注销、关机时不能执行，条件恢复后由系统尝试补跑。

每日分类是一个有界批次，模型不能调用工具，只选择原始输入 ID 的 keep/reject。
每周生成提案供人工审阅，绝不自动改写 rules。后台模型调用使用用户确认的账号。
不设 AI Credits 上限；每次调用有超时保护，不自动无限重试。

## 验收

- 重复采集不重复计数，并发采集无条目丢失。
- 无输入不调用模型；响应无效、超时、认证失败不消费待处理输入。
- 每条提案至少有两个不同来源；没有人工确认不修改全局规则。
- 日志、退出码、最近运行记录可查；生成视图可重建。
- 定时任务配置读回并通过真实启动验证，不能仅以“注册成功”宣称完成。
