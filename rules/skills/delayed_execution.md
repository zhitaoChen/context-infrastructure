# 延时与定时执行

先确认任务是否必须在关闭 Copilot 后继续。两种机制不能互相替代：

| 需求 | 当前 Windows/Copilot 机制 |
|---|---|
| 当前会话中的短期提醒或重复 prompt | Copilot session schedule，仅在该会话运行时触发 |
| 关闭 CLI 后仍执行 | Windows Task Scheduler，调用非交互命令并记录退出码 |
| 跨注销运行 | 另行配置系统凭据或服务账号；不要在聊天索取密码 |

记忆系统的已配置实现见 `docs/CRONTAB.md`，只允许非敏感工作流记忆和审阅提案，
不能借这个入口调度任意发布、交易、删除或项目命令。

其他任务应独立定义作用域、触发时间、时区、运行身份、并发策略、超时、
日志和补跑行为。创建后读回配置，并用安全输入执行一次实际任务。
停止前核实准确任务名/进程 ID，不按进程名称批量终止。

不在 Windows 默认使用 `nohup`、`disown`、cron 或旧 OpenCode 服务。
后台进程只保持到会话结束，除非用户明确要求并已配置独立持久运行。
